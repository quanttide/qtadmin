# 角色页设计

角色页承载「责任划分」：任务类型 → 默认评审人。

## 定位

对齐洞察 review-path 第二步「责任划分」：任务绑定角色槽位而非具体人，评审人随槽位变化；任务类型决定评审人（常规 = 直接指导者，政策类 = 秘书处，重大 = 创始人）。

## 数据

RoleType 枚举（`lib/models/task.dart`）：

| 任务类型 | 默认评审人 |
|----------|-----------|
| 常规 | 直接指导者 |
| 政策类 | 秘书处 |
| 重大 | 创始人 |

评审人可被覆盖：任务卡片上的评审人按分配时刻的槽位定格，槽位修改影响后续新建任务。

## 交互

- 列表：每种任务类型一张卡片，编辑「默认评审人」字段，提交生效
- 修改后新建任务即用新评审人
