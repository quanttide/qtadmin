# 摩擦页设计

摩擦页承载「摩擦盘点」：一次摩擦一条标准，比从原则推导更快。

## 定位

对齐洞察 review-path 第一步「摩擦盘点」：从高频摩擦开始，复盘四问（谁缺位、缺什么标准、标准怎么写、进哪本册子），区分偶发与结构性——偶发摩擦不立制度，结构性缺位才立。

## 数据

Friction 模型（`lib/models/friction.dart`）：

| 字段 | 说明 |
|------|------|
| scene | 场景描述（发生了什么） |
| missingRole | 谁缺位 |
| standardDraft | 标准怎么写（条件 + 动作 + 证据草稿） |
| handbook | 进哪本册子 |
| kind | 类型（偶发 / 结构性） |
| date | 登记日期 |

## 交互

- 列表：卡片展示场景、缺位角色、标准草稿、册子与类型标签
- 登记：表单引导复盘四问，类型默认结构性（制度修订的主要来源）
